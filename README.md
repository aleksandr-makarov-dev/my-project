# MyProject

React and TypeScript application using Vite and TanStack Router.

## Prerequisites

- Use a Node.js version supported by the installed dependencies. This setup was checked with Node.js 24.21.0 and npm 11.19.0.
- Install dependencies with `npm ci`.
- Install Playwright's Chromium binaries with `npx playwright install chromium`. The download requires network access. On Linux CI, use `npx playwright install --with-deps chromium` to also install system dependencies.
- Keep `127.0.0.1:4173` free for browser tests. Playwright starts its own production preview server and fails if the port is occupied.

If browser binaries must stay inside the project, set `PLAYWRIGHT_BROWSERS_PATH=0` both when installing and when running Playwright. For example, in PowerShell:

```powershell
$env:PLAYWRIGHT_BROWSERS_PATH = '0'
npx playwright install chromium
npm run test:e2e
```

## Commands

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the Vite development server. |
| `npm run lint` | Check application, tests, and configuration with ESLint. |
| `npm run typecheck` | Check the referenced application and tooling TypeScript projects, including tests. |
| `npm test` | Run Vitest in watch mode. |
| `npm run test:run` | Run source tests once. |
| `npm run build` | Run `tsc -b`, then build the production application. |
| `npm run test:e2e` | Build once, then run Chromium browser scenarios. |
| `npm run test:e2e:ui` | Build once, then open Playwright's interactive test runner. |
| `npm run check` | Run lint, Vitest once, and the build-first E2E workflow. |
| `npx playwright show-report` | Open the most recent HTML browser test report. |

Use `npm run check` for the full validation workflow; no separate build is needed before `test:e2e`. To rerun browser tests against an already current production build, use `npx playwright test`.

## Test organization

Vitest discovers only `src/**/*.test.ts` and `src/**/*.test.tsx`. Its config merges the Vite config so tests retain the application alias (`@/` resolves to `src/`), React transforms, and other plugins. The alias is also declared in `tsconfig.app.json`; the root TypeScript config keeps the existing project references.

Component tests use jsdom. `src/test/setup.ts` imports jest-dom matchers and explicitly cleans up rendered DOM after every test. `src/test/server.ts` exports the MSW Node server. Register responses inside each test with `server.use(...)`; handlers are reset after each test and the server closes after the suite. Unexpected HTTP requests fail the test even if application error handling catches the rejected request. No backend is needed for these mocked API tests.

Initial source tests cover JSON request headers and response unwrapping, ProblemDetails normalization and fallback errors, date padding/leap days/millisecond timestamps/invalid inputs, and dialog keyboard opening, accessible description, dismissal, and focus restoration. Date tests use local dates so their expectations do not depend on the machine's timezone.

Playwright discovers browser scenarios under `e2e/` and currently runs Chromium only. It serves `dist/` with `vite preview` at `http://127.0.0.1:4173`, using a strict port and no reuse of an existing server. The smoke test checks the actual home heading, “Welcome Home!”, and Home navigation. It does not require authentication or a backend and does not establish frontend/backend integration coverage.

Failed browser tests retain traces and screenshots under `test-results/`. The HTML report is under `playwright-report/`. Reports, coverage, and browser artifacts are ignored by Git and ESLint. Open a retained trace with `npx playwright show-trace <path-to-trace.zip>`.

## Generated routes

The installed TanStack Router Vite plugin generates `src/routeTree.gen.ts` when Vite initializes (including Vitest's merged Vite configuration). Do not edit this file manually. If it is absent or stale after route changes, initialize Vite with `npm run dev` or run `npm run test:run` before `npm run typecheck` or `npm run build`; both TypeScript commands check types before the production Vite build starts. Generation cannot resolve links to routes that do not exist.
